## 📝 Описание

Задача: Спроектировать одностраничный, визуально пафосный и минималистичный сайт-портфолио для двойной персоны (Пупа & Лупа). Сайт должен выглядеть как визитная карточка высококлассного креативного агентства, но с юмористическим подтекстом.

Основные требования к структуре :

Главный Акцент: Сайт должен быть премиальным, монохромным, с большим количеством "воздуха" и асимметричной сеткой. Визуальный язык должен контрастировать с абсурдностью темы.

Двойственность: Вся структура должна подчеркивать концепцию "Пупа" и "Лупа" как двух неразрывных, но контрастных сущностей одного человека.

Используй контрастные шрифты или цвета (например, полупрозрачный/жирный) для обозначения двух "половин".

Секции (Content Blocks):

Hero Section: Крупный, типографический заголовок Пупа & Лупа. Под ним короткий, пафосный слоган, например: "The Duality of Modern Existence" или "Two Sides of One Genius". Должно быть место для фонового видео (или GIF) в качестве Hero.

Manifesto / About Section: Разделенный на две колонки блок: одна для "Пупа" (например, текст про его "свершения"), вторая для "Лупа" (про его "неудачи" или "челленджи"). Каждый блок с отдельной небольшой подписью и плейсхолдером для фото.

"Works" / "Projects" (Showcase): Сетка 2x2 или 3x1. Каждый элемент сетки — это "достижение" или "проект". Дай название: "Pupa's Triumphs" и "Lupa's ... Lessons". Должно быть место для изображений или коротких видеороликов в каждой ячейке.

"Testimonials" / "Praise & Critique": Два контрастных отзыва. Один - хвалебный ("Я ЗА ПУПУ"), другой - саркастический/критичный ("Я ЗА ЛУПУ"). Использовать плейсхолдеры для аватаров (фото друзей).

Contact / Call to Action: Минималистичный футер. Вместо формы - только крупный текст с призывом к действию (дать Пупе за Лупу), под которым будут ссылки на соцсети (только текст, без иконок).
